### Notes on the palette

- **`bone` and `paper` are 7 hex points apart** (`#EDE3CE` vs `#F4EBD9`). Cards do not separate from the page by colour alone. Separation comes from the drop shadows, which is why removing a shadow can make a card vanish.
- **`plum` is nearly dead.** Outside of gradient stops it appears once in the whole codebase. If you want a fourth accent it is available.
- **`paper-deep` is an admin-only colour** in practice. One use on the public side.

## Table 2: Fonts

All four are self-hosted variable fonts loaded with `next/font/local` in `app/layout.tsx`. No Google Fonts, no CDN. The CSS variables are attached to `<html>`; the Tailwind classes are mapped in `tailwind.config.ts`.

| Name | File | Class / variable | Weights | Used for |
|---|---|---|---|---|
| Trench Slab Variable | `public/TrenchSlab_Complete/Fonts/WEB/fonts/TrenchSlab-Variable.woff2` | `font-display` / `--font-trench-slab` | Variable `wght` 300 to 700, **defaults to 700** | Every heading. Applied automatically to `h1`-`h6` in `globals.css`, and explicitly via `font-display` on countdown digits and big numbers. |
| Alpino Variable | `public/Alpino_Complete/Fonts/WEB/fonts/Alpino-Variable.woff2` | `font-body` **and** `font-mono` / `--font-alpino` | Variable `wght` 100 to 900, **defaults to 900** | All body copy, and all uppercase wide-tracked metadata. Set on `<body>` in `globals.css`. |
| Telma Variable | `public/Telma_Complete/Fonts/WEB/fonts/Telma-Variable.woff2` | `font-telma` / `--font-telma` | Variable `wght` 300 to 900, defaults to 900 | **Nothing. Loaded but never used.** See drift notes. |
| HALLOWEEN | `public/fonts/halloween.ttf` | `font-halloween` / `--font-halloween` | Static, weight 400 only | Exactly one line: "An iconic 37-year tradition" on the homepage hero plank, `app/(public)/page.tsx:39`. Deliberately scoped. Does not hold up at heading sizes. |

### Notes on the fonts

- **`font-mono` is not a monospace font.** It is aliased to Alpino, the same family as `font-body`. Anything relying on character alignment (a table of figures, an order number column) will not align. The class name is a leftover from the mockup.
- **Both variable fonts default to their heaviest weight.** Trench Slab defaults to 700 of a 300-700 range, Alpino to 900 of 100-900. Body text is rendering at 900 unless a `font-normal` or `font-light` overrides it. That is why the site reads heavy. It is not a bug, but it is worth knowing you have a 100-to-900 range available and are using one end of it.
- **Base font size is 22px**, set on `<body>` in `globals.css`, with `line-height: 1.6`. Larger than a typical 16px default, so Tailwind's `text-sm` and `text-xs` are proportionally bigger than they would be elsewhere.
- **Telma ships to every visitor and renders nothing.** Deleting the loader from `app/layout.tsx` removes a font download from every page load.

## Brand drift: hardcoded values

Everything below is a colour that does not come from the Tailwind palette. Three categories: deliberate, harmless, and worth fixing.

### Deliberate. Leave alone.

| Location | Value | Why it is not drift |
|---|---|---|
| `app/(public)/sponsors/page.tsx:55` | `#4B1F68` | Aussie Home Loans purple. Sampled from the supplied logo file so the plate meets the artwork with no seam. |
| `app/(public)/sponsors/page.tsx:66` | `#192E5B` | Prestige Auto navy, same reason. |
| `app/(public)/sponsors/page.tsx:97` | `#EB0029` | Vision Personal Training red, same reason. |
| `app/(public)/sponsors/page.tsx:107` | `#B7D5DF` | The Little Marionette pale blue, same reason. |
| `app/(public)/sponsors/page.tsx:168` | `#FFFFFF` | Default logo plate. Logos arrive with white baked in, so a cream plate would show a white rectangle inside it. |

These are **other companies' brand colours**. They must not be replaced with our tokens.

### Harmless, but off-palette

| Location | Value | Note |
|---|---|---|
| `app/(public)/page.tsx:25` | `from-black/40 via-black/50 to-black/30`, `md:` variants to `/70` | Pure black scrim over the hero photo. A darkening layer, not a brand colour. `ink` `#1A1A1A` would be marginally warmer and more on-brand. |
| `app/(public)/attractions/AttractionImage.tsx:61` | `bg-black/85` | Lightbox backdrop. Same reasoning. |
| `app/components/Countdown.tsx:30` and several pages | `rgba(0,0,0,0.8)` etc in `text-shadow` | Text shadows for legibility over photos. Pure black is the correct choice for a shadow. |

### Worth fixing

| Location | Value | Problem |
|---|---|---|
| `app/globals.css:38` | `outline: 2px solid #2D3A2E;` | This is `forest`, written as a literal. It is the **keyboard focus ring on every focusable element on the site**, so it is the single most load-bearing hardcoded colour here. If `forest` ever changes in `tailwind.config.ts`, focus rings silently keep the old value. Use `theme('colors.forest')`. |
| `app/admin/tasks/TaskBoard.tsx:440` | `color: tag.color \|\| "#5A6B4F"` | This is `moss`, written as a literal, as the fallback when a tag has no colour set. Admin only, low blast radius, but the same silent-drift problem. |

### Not hex, but the same issue: `rgba()` shadows

Every drop shadow on the site is written as an `rgba()` literal rather than a token. They do map to the palette:

| Literal | Token | Where |
|---|---|---|
| `rgba(26,26,26,…)` | `ink` `#1A1A1A` | The standard card shadow. Used on `/`, `/attractions`, `/faq`, `/auction`, `/sponsors`, `/tokens`, `/welcome`, `/checkout/success`. Roughly 20 occurrences. |
| `rgba(216,122,63,…)` | `pumpkin` `#D87A3F` | The token bundle card glow on `/tokens`, `0.30` resting and `0.55` on hover. |
| `rgba(184,92,46,…)` | `rust` `#B85C2E` | The sponsor card glow on `/sponsors`, `0.22` resting and `0.45` on hover. |

This is normal for Tailwind. Arbitrary shadow values cannot reference tokens without a plugin or CSS variables. Recording the mapping here is the practical fix, so anyone changing `ink`, `rust` or `pumpkin` knows to grep for the matching `rgba()`.

### Other findings

- **Telma Variable is loaded on every page and used nowhere.** `app/layout.tsx:30` declares it, `tailwind.config.ts:30` maps `font-telma`, and no component ever applies the class. It is a font download on every page load that renders nothing.
- **`font-mono` is Alpino, not a monospace font.** Anything relying on character alignment will not align.
- **Both variable fonts default to their heaviest weight** (Trench Slab 700 of 300-700, Alpino 900 of 100-900). If the site reads heavier than intended, that is why, and the lighter end of both ranges is available at no extra download.
